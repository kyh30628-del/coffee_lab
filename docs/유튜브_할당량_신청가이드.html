0. 먼저 — 자주 묻는 것부터

개인(비사업자)도 신청 되나?네, 됩니다. 주체 유형에서 Individual user(개인) 선택, 법인명엔 Self, 규모엔 Independent Developer를 고르면 사업자 정보 없이 진행됩니다.
로그인한 Gmail ≠ 신청자여도 되나?기술적으로는 가능하나 권장하지 않음. 양식엔 '연락처 이메일'을 따로 적고 회신은 거기로 옵니다. 다만 할당량 받을 Google Cloud 프로젝트를 소유한 계정으로 로그인 + 그 계정을 연락처로 쓰는 게 검증·적용이 깔끔합니다. (= 유튜브 키 만든 그 계정으로 로그인)
비용은?무료. 단 구글이 실제 검토(audit)를 합니다. 승인까지 며칠~몇 주, 회신 기한은 공지 없음.
꼭 필요한 준비물?① Cloud 프로젝트 번호 ② 공개 개인정보처리방침 URL ③ 홈/약관/방침 스크린샷 (아래 §1)
나중에 사장님 구독(유료)으로 가도 약관 위반 아닌가?아니요(조건부 OK). 구독이 내 분석·마케팅 도구 판매면 됨. 유튜브 데이터/영상을 팔거나 페이월 뒤에 두면 위반. 자세한 선은 §3.
가장 흔한 거부 사유 — ① 공개 개인정보처리방침 없음 ② 사용 사례가 모호 ③ 스크래핑·대량다운로드처럼 보임. 이 가이드는 셋 다 피하도록 작성돼 있습니다.

1. 신청 전 준비물 (3가지)

① Google Cloud 프로젝트 번호

console.cloud.google.com → 유튜브 키 만든 프로젝트 선택 → 대시보드 상단 "프로젝트 번호"(숫자) 복사. (프로젝트 ID 아닌 번호)

② 공개 개인정보처리방침 URL (필수 — 없으면 거의 거부)

우리 서비스는 개인정보를 안 받지만, 방침 페이지 자체는 공개로 있어야 합니다. 준비된 페이지:

https://coffee-lab-product-builder.vercel.app/privacy https://coffee-lab-product-builder.vercel.app/terms (이용약관)

※ 이 페이지들을 만들어 배포해 둡니다(아래 별도 안내). 방침엔 "YouTube API 사용·데이터·삭제정책"과 "Google 개인정보처리방침 링크"가 보여야 통과에 유리.

③ 스크린샷 3장(이미지/PDF)

  • 홈페이지 화면 (랜딩 — 서비스가 뭔지 보이게)
  • 개인정보처리방침 페이지 (YouTube 관련 문구 + Google 방침 링크 + 삭제정책 보이게)
  • 이용약관 페이지
가점 팁: 카페 상세에서 "▶ YouTube · 채널명 · 영상 보기"가 보이는 화면(예: '제이든 커피 로스터스' 페이지)도 한 장 캡처해두면, "메타데이터+원본 링크"라는 우리 사용 방식을 증명하기 좋습니다.

YouTube 비즈니스 설명 (100자 이상 필수)

아래를 그대로 붙여넣으세요(영문 권장):

I operate "Dongne Coffee Note", a local cafe discovery guide for the Seoul metropolitan area. I use the YouTube Data API (search.list, videos.list, commentThreads.list) to find public videos about specific local cafes by name, and retrieve only the video title, description, publish date, and a few top comment TEXTS (no commenter identity/usernames) to cross-verify and enrich publicly sourced review data. I do NOT download, host, embed, or re-host any video; every video links back to YouTube and watching is always free (never gated behind login, payment, or subscription). The service is free for consumers; I plan a future paid subscription for cafe OWNERS offering my own marketing/analytics tools — NOT access to, or resale of, YouTube data or metrics. I request a higher daily quota to backfill metadata for ~3,000 local cafes (currently limited to ~95/day).

Detailed Justification (할당량 사유) — 붙여넣기

Default 10,000 units/day only allows ~95 search.list calls per day. I need to backfill YouTube metadata (title/description/top comments) for ~3,000 local cafes in the Seoul area, and keep it fresh as new cafes are added. A higher daily quota lets me complete this backfill in days instead of months, while staying fully within the Terms of Service — metadata only, always linked back to the original YouTube videos, no downloading or re-hosting.
필수 첨부: §1의 스크린샷 3장(홈·개인정보처리방침·이용약관) + (가점) 카페 상세의 ▶YouTube 화면.

✅ 우리가 지키는 선 (이대로면 안전)

항목우리 상태
영상 재호스팅안 함 — 메타데이터만, 원본 YouTube로 링크
영상 시청 제한없음 — 클릭하면 바로 재생. 구독·로그인·요금 뒤에 숨기지 않음

유튜브 데이터 재판매안 함 — 구독은 사장님용 마케팅·분석 도구 판매, 유튜브 데이터/지표 판매 아님
파생 지표 판매안 함 — 점수는 네이버 후기 중심, 유튜브는 '언급 여부' 보조
저장·삭제교차검증 캐시만, 주기 갱신, 정책 한도(통상 30일) 내 보관, 삭제요청 30일 내
구독(유료) 전환 — 이 3가지만 지키면 OK
① 구독 명목은 "유튜브 영상 보기"가 아니라 사장님 분석·마케팅 도구 ② 어떤 영상도 페이월 뒤에 두지 않기 ③ 유튜브 통계(조회·참여)를 가공해 "유튜브 성과 분석"으로 팔지 않기.

  • 유튜브 데이터 재판매 / 유튜브 대체 서비스 → 우리는 '안내·검증 보조 소스'

4. 제출 · 그 후 · 핵심 체크

제출 전 마지막 체크

로그인 = 유튜브 키 만든 그 Google 계정인가

개인정보처리방침·이용약관 페이지가 공개 URL로 열리는가

방침에 "YouTube API 사용·데이터·삭제" + "Google 개인정보처리방침 링크"가 있는가

사용 사례에 "메타데이터만 · 원본 링크 · 다운로드/재호스팅 안 함"이 분명한가

스크린샷 3장 첨부했는가

제출 후

  • 제출 사본이 입력한 이메일로 자동 회신됩니다(보관).
  • 구글 API팀이 검토 후 회신 — 기한 공지 없음(며칠~몇 주).
  • 추가 자료 요청이 오면 빠르게 회신할수록 좋습니다.
  • 승인되면 그 프로젝트의 일일 한도가 상향됩니다.
