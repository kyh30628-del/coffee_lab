# 유료화(사장님 구독 결제) 체크리스트

> 작성 2026-06-21. **현재는 무료 7일 체험만 운영 → 결제 의무 없음.**
> 아래는 **유료 구독(₩9,900/월) 과금을 켤 때** 순서대로 진행하면 되는 목록.
> 핵심: 사업자등록 → PG 계약 → 통신판매업 신고 → 결제 연동 → 표시·약관 점검 → 세무.

---

## 0. 지금까지 코드로 끝난 것 (재확인용)
- [x] 사장님 7일 무료 체험 신청 → 관리자 승인 → 이메일 PIN → 내 카페 분석 직행
- [x] 사칭 방지: 사업자등록증 이미지 + 법적 동의 + 접속기록(IP/UA) DB 증빙
- [x] 이미 인증된 카페 탈취 차단(409), 승인 시 verified 기록(주의의무 증거)
- [x] 관리자 **🚫 사칭/위반 즉시정지**(PIN 즉시 무효 + 사유 기록)
- [x] 약관·개인정보방침: 정기결제·청약철회·환불(3영업일·연15%)·약관변경통지·분쟁해결·사칭금지 조항
- [x] `/business` 사업자정보·환불정책 페이지 골격(미입력 항목은 `[입력 필요]`)
- [ ] **결제(PG) 연동은 아직 없음** — 현재 "구독 신청"은 신청만, 실제 과금 X (아래 4단계에서 구현)

---

## 1. 사업자등록 (홈택스, 무료·당일)
- [ ] **개인사업자 등록** (홈택스 또는 세무서). 업종: 정보통신업/플랫폼·온라인광고(예: 소프트웨어 개발·공급, 포털·온라인정보제공) 코드 선택
- [ ] **과세유형 결정**: 간이과세자 vs 일반과세자
  - 간이과세: 연 매출 1.04억 미만, 부가세 부담↓, **통신판매업 신고 면제** 가능
  - 일반과세: 세금계산서 발행 등 필요 시
- [ ] 사업장 주소(자택 가능), 상호 확정
- 산출물: **사업자등록번호, 상호, 대표자, 주소** → `/business` 채움

## 2. PG(결제대행) 계약
- [ ] **토스페이먼츠 / 나이스페이 / KG이니시스** 등 PG 가입·심사(사업자등록증 필요)
- [ ] **정기결제(빌링키)** 지원 상품으로 계약 — 월 자동결제용
- [ ] **‘구매안전서비스 이용확인증’** 발급받기 → **통신판매업 신고 서류로 사용**
- 산출물: **PG사명, 구매안전서비스 이용확인증**

## 3. 통신판매업 신고 (정부24, 2~3일)
- [ ] **면제 여부 먼저 확인**: ① 간이과세자 이거나 ② 직전년 거래 50회 미만이면 면제
- [ ] 면제 아니면 **정부24 > 통신판매업신고** 신청 (사업자등록증 + 구매안전서비스 이용확인증)
- [ ] **등록면허세** 납부(연 1회, 인구 50만↑ 시 약 40,500원 / 그 외 12,000~22,500원)
- 산출물: **통신판매업 신고번호** → `/business` 채움
- ⚠️ 미신고로 유료 판매 시 **과태료**. 유료 켜기 전 필수.

## 4. 결제 연동 (코드 작업 — 내가 구현)
- [ ] PG **정기결제(빌링키 발급 → 매월 자동결제)** 연동
- [ ] 결제 화면에 **금액·부가세 포함여부·결제주기·자동갱신** 명확 고지
- [ ] **승인(activate) 시 PG 빌링 등록**, 해지 시 빌링 해지
- [ ] 결제 실패/카드만료 시 재시도·알림·자동 해지 처리
- [ ] 결제 화면·푸터에 **사업자정보(/business)·환불정책·약관·방침 링크** 노출(법적 표시의무)
- [ ] (선택) 영수증/세금계산서·현금영수증 처리

## 5. `/business` 페이지 [입력 필요] 채우기
- [ ] 상호 / 대표자 / 사업자등록번호 / 통신판매업 신고번호 / 사업장 주소 / 고객센터 전화 / PG사
- [ ] 부가세 포함 여부, 결제주기(매월 자동결제), 환불 처리 영업일(기본 3영업일)
- → 값 정해지면 알려주면 코드에 바로 반영

## 6. 약관·방침 최종 점검
- [x] 정기결제·자동갱신·증액 사전동의 (약관 6조)
- [x] 청약철회·환불(3영업일·연15%·디지털 개시분 제한+시험사용) (약관 6조 / `/business`)
- [x] 약관변경 통지·회원탈퇴·이용제한 (약관 7조)
- [x] 분쟁해결·준거법·관할 (약관 9조)
- [ ] **결제 시 ‘자동결제 동의’ 별도 체크박스** 추가(가입 모달)
- [ ] (권장) **변호사·세무사 1회 검토** — 면책·환불·세무

## 7. 세무 운영
- [ ] 부가가치세 신고(간이=연 1회 / 일반=연 2회), 종합소득세(연 1회)
- [ ] PG 정산 내역 ↔ 매출 기록 일치 관리
- [ ] (권장) 세무 대행 또는 자동기장 서비스(삼쩜삼·자비스 등)

## 8. 운영 프로세스(켠 뒤)
- [ ] 환불 요청 → **3영업일 내** 처리(지연 시 연15% 가산)
- [ ] 사칭 신고 → 관리자 **🚫 즉시정지** 버튼으로 차단(이미 구현)
- [ ] 해지/만료 → 우선노출 OFF·PIN 무효(이미 구현)

## 빠른 순서 요약
**사업자등록(홈택스) → PG계약(구매안전확인증) → 통신판매업 신고(정부24) → 결제연동(코드) → /business·약관 마무리 → 세무 셋업.**
무료 체험 단계에선 1~4 불필요. **유료 ₩9,900을 켜는 시점에 1번부터 한 번에 진행.**
