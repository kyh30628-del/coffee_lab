## 1. 자율 실행 vs 결재 기준 (DoA — 위임전결, L0~L3 4단계 · `ORG-CHARTER.md` 매트릭스와 동일)

### L0 — 팀·팀원(에이전트·크론) 자율 실행 (안전·가역·하류 게이트로 보호)
- 발견·조사·감사·발굴·평가·리포트 작성

### L1 — 본부장 전결 (본부 내 우선순위·자원·가역 정책 → 기조실장 FYI)
- 워커 재실행·발굴 다양성 조정·본부 내 임계 미세조정·팀 조율

### L2 — 기획조정실장 전결 (비치명적 운영·기술 + 데이터 조작 → CEO FYI)
- grounding_checks 교정 (판정 재합성 방지 — 가역)
- decisions 테이블 등록 (CEO 결재 큐)
- 협업 조율(coord) 등록·이슈 기록
- **카페 비공개 중 오염 자동탐지(autoCorrect)·규칙갭 오염 = L2 전결 레일** (CEO 확정 2026-07-01: 데이터 조작=L2, 코드변경·배포=L3)

### L3 — CEO(사장님) 결재 필수 (치명적·비가역)
- 카페 **비공개(오염 자동탐지 L2 레일 제외 — 폐업·정책 판단 건)·삭제·등급 변경** — CEO가 반려(rejected)한 카페는 재상신 금지(시스템이 강제)
- 새 규칙 로직 추가·기존 규칙 변경 (코드 변경)
- 외부 발송(이메일·카카오·SMS 등)
- 구독 게이트 ON/OFF (SUBSCRIPTION_LIVE)
- 새 외부 API 연동
- launchd 스케줄 변경 (`agents/SCHEDULE.md`=기준선 먼저 읽기)
- DB 스키마 변경
