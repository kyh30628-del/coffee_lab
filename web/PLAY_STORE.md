# 📱 동네 커피 노트 — Google Play 출시 준비 패키지

웹앱(PWA)을 TWA로 감싸 Play Store에 올리는 데 필요한 모든 것. 기술 토대는 코드에 반영됨.

---

## 0. 계정 — 개인 vs 조직
- **개인 계정**: 사업자 등록 불필요(본인 신분증만). 단 **테스터 12명 + 14일 비공개 테스트** 의무.
- **조직 계정**: D-U-N-S(사업자) 필요. 테스트 면제 가능.
- 변환 불가(개인↔조직). 나중에 사업자 생기면 **새 조직 계정 만들어 앱 이전(transfer)**.
- 명의자가 미래 사업자와 달라도 됨 — 지금은 개인 자격으로 출시.
- 등록비 **$25 일회성**(평생, 앱 무제한).

## 1. 기술 토대 (✅ 코드 반영 완료)
- `public/manifest.json` — id·scope·lang·categories + maskable 아이콘
- `public/icon-maskable-512.png` — 적응형 아이콘(안전영역 패딩)
- `public/.well-known/assetlinks.json` — 도메인 인증(서명 지문만 교체 대기)
- `twa-manifest.json` — Bubblewrap 참조 설정(푸시 알림 ON)
- 개인정보처리방침: https://dongnecoffeenote.com/privacy ✅

## 2. 스토어 등록정보 (복붙)

**앱 이름** (30자): `동네 커피 노트`

**간단한 설명** (80자):
`광고·가짜 후기를 거른 진짜 정보. 데이터로 검증한 수도권 동네 카페 가이드.`

**자세한 설명**:
```
☕ 광고 말고, 진짜 후기로 검증한 동네 카페

"이 동네 괜찮은 카페 어디지?" 검색하면 광고·협찬·가짜 후기만 가득하죠.
동네 커피 노트는 네이버 공개 후기를 AI로 교차검증해 '진짜 방문 후기'만 가려 보여줍니다.

■ 뭐가 다른가
· 광고·협찬·체험단 글 자동 제외 — 진짜 후기만
· 동명·다른 지점 후기 오염 차단 — 정확한 '그 카페' 정보만
· 후기 데이터로 뽑은 강점(예: 직접 로스팅 상위 3%, 작업하기 좋은) 한눈에
· 통창뷰·주차·디저트·반려동물 등 구체 포인트를 후기 빈도로 정리

■ 이렇게 쓰세요
· 우리 동네 검증된 카페를 지도에서 찾기
· 작업·데이트·혼커피·빵 등 원하는 '결'로 거르기
· 내 위치 기준 가까운 진짜 카페 추천

■ 수도권(서울·경기·인천) 6,000곳 이상, 계속 추가 중

가짜 정보에 속지 말고, 데이터로 검증한 진짜 동네 카페를 만나보세요.
```

**카테고리**: 식음료 · **태그**: 카페, 카페 추천, 동네 카페, 카페 지도

## 5. 출시 단계
1. **Play 개발자 계정** 생성($25, 신분증 인증 2~3일)
2. **PWABuilder.com** → `https://dongnecoffeenote.com` 입력 → Android 패키지 생성
   - (또는 Bubblewrap CLI + 위 twa-manifest.json)
3. 빌드 후 나온 **SHA256 서명 지문**을 개발자에게 전달 → `assetlinks.json` 교체·재배포
4. Play Console: 패키지 업로드 + 위 등록정보·데이터보안·개인정보 URL 입력
5. **비공개 테스트(12명·14일)** → 정식 출시 신청

---

## 6. 출시 후 — 홍보 현실
스토어는 **유통 채널**이지 홍보 채널이 아님. 다운로드는 외부에서 데려와야 함(바이럴·SNS).
앱의 진짜 가치 = **푸시 알림 리텐션 + 신뢰도**. (twa-manifest의 enableNotifications=true로 켬)
